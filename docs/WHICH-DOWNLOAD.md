# Which download? / 选哪个包？

**Most people → `DayNight-lite.zip` only.**  
**大多数人 → 只下 `DayNight-lite.zip`。**

| File | Size | English | 中文 |
|------|------|---------|------|
| **`DayNight-lite.zip`** | ~0.5 MB | **Start here.** Needs [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0). | **首选。** 需已安装 [.NET 8 桌面运行时](https://dotnet.microsoft.com/download/dotnet/8.0)。 |
| `DayNight-full.zip` | ~60 MB | No .NET install. One self-contained `.exe`. | 电脑没有 .NET 时用。自包含单文件。 |
| `DayNight-dir.zip` | ~60 MB | Same as full, folder of files. | 与 full 相同，文件夹形态。 |
| `DayNight-src.zip` | ~1 MB | Source + the same lite exe. | 源码 + 与 lite 同款 exe。 |

DayNight makes your PC switch light/dark **like a phone**, so Follow-system apps actually follow.  
昼夜让电脑**像手机一样**按时切换浅色/深色，让「跟随系统」的软件真正跟着变。
